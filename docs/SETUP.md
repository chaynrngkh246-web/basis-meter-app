# วิธีเปิดใช้งาน (ไม่ต้องพิมพ์คำสั่งใดๆ ใช้การคลิกอย่างเดียว)

ทำครั้งเดียวโดยหัวหน้าทีม ใช้เวลาประมาณ 10 นาที จากนั้นส่งลิงก์ให้ช่างที่เหลือ
เปิดใช้ได้เลย **ช่างไม่ต้องสมัครอะไรทั้งสิ้น**

## ขั้นที่ 1 — เปิดเว็บให้ใช้งานได้ (GitHub Pages)

1. เข้าไปที่หน้า repository นี้บน GitHub
2. กดแท็บ **Settings** (ด้านบนขวา)
3. เมนูซ้ายมือ เลือก **Pages**
4. หัวข้อ **Build and deployment** → **Source** เลือก **Deploy from a branch**
5. **Branch** เลือก `claude/utility-meter-logging-app-punz8c`
   และช่องถัดมาเลือก **/docs** → กด **Save**
6. รอประมาณ 1–2 นาที แล้วรีเฟรชหน้า จะขึ้นลิงก์สีเขียวประมาณนี้

   ```
   https://chaynrngkh246-web.github.io/basis-meter-app/
   ```

   **นี่คือลิงก์เว็บแอปของคุณ** เปิดได้ทุกคน ไม่ต้องมีบัญชีอะไร

## ขั้นที่ 2 — สร้างฐานข้อมูล (Firebase ฟรี)

ใช้บัญชี Google ธรรมดาของคุณ ไม่ต้องผูกบัตรเครดิต

1. เปิด https://console.firebase.google.com แล้วล็อกอินด้วย Google
2. กด **Create a project** → ตั้งชื่อ เช่น `bisb-meter` → กด Continue
3. หน้า Google Analytics ให้ **ปิด** (Disable) แล้วกด **Create project** → รอสักครู่ → Continue
4. เมนูซ้าย กด **Build** → **Firestore Database** → **Create database**
   - Location เลือก **asia-southeast1 (Singapore)**
   - เลือก **Start in production mode** → **Create**
5. พอสร้างเสร็จ กดแท็บ **Rules** ด้านบน แล้ว **ลบข้อความเดิมทั้งหมด**
   วางข้อความนี้แทน แล้วกด **Publish**

   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /{document=**} {
         allow read, write: if true;
       }
     }
   }
   ```

   > อ่านเรื่องความปลอดภัยของกฎนี้ในหัวข้อท้ายไฟล์

6. กดรูป **เฟือง ⚙️** มุมซ้ายบน → **Project settings**
7. เลื่อนลงล่างสุดหัวข้อ **Your apps** → กดไอคอน **`</>`** (Web)
8. ตั้งชื่อเล่นอะไรก็ได้ เช่น `meter` → กด **Register app**
9. จะมีข้อความโค้ดขึ้นมาแบบนี้ **ให้คัดลอกทั้งก้อน**

   ```
   const firebaseConfig = {
     apiKey: "AIza...",
     authDomain: "bisb-meter.firebaseapp.com",
     projectId: "bisb-meter",
     ...
   };
   ```

## ขั้นที่ 3 — เชื่อมแอปกับฐานข้อมูล

1. เปิดลิงก์เว็บแอปจากขั้นที่ 1 บนคอมหรือมือถือ
2. จะเจอหน้า **"เชื่อมต่อฐานข้อมูล"** → วางข้อความที่คัดลอกมาลงในช่อง → กด **เชื่อมต่อ**
3. ใส่ **ชื่อคุณ** และ **ตั้งรหัส PIN 4 หลัก** → กด **เริ่มใช้งาน**
4. กดปุ่ม **"ติดตั้ง 10 จุดของ BISB"** → ได้จุดมิเตอร์ครบทั้ง 10 จุดทันที
5. ไปที่ **ตั้งค่า › ทีมช่าง** เพิ่มช่างอีก 7 คน (ชื่อ + PIN คนละรหัส)

---

## ขั้นที่ 4 — ส่งลิงก์ให้ทีม

1. ในแอป ไปที่ **ตั้งค่า › ข้อมูล**
2. หัวข้อ **"ลิงก์สำหรับทีมช่าง"** กด **คัดลอกลิงก์**
3. วางส่งในกลุ่ม LINE ได้เลย

ช่างแต่ละคนเปิดลิงก์นั้น → เลือกชื่อตัวเอง → ใส่ PIN → ใช้งานได้ทันที
ไม่ต้องตั้งค่าอะไรอีก (ลิงก์นี้พาไปที่ฐานข้อมูลเดียวกันให้อัตโนมัติ)

**แนะนำให้ทุกคนเพิ่มลงหน้าจอโฮม** จะใช้เหมือนแอปจริง
- iPhone (Safari): ปุ่มแชร์ → เพิ่มลงในหน้าจอโฮม
- Android (Chrome): เมนู ⋮ → ติดตั้งแอป / เพิ่มลงในหน้าจอหลัก

## วิธีใช้ประจำวัน

1. เปิดแอป → หน้าหลักแสดง 10 จุด พร้อมสถานะว่าวันนี้บันทึกครบหรือยัง
2. แตะจุดที่จะบันทึก → **ถ่ายรูป** → **กรอกเลขมิเตอร์ทุกตัวในจุดนั้น**
   (ระบบโชว์เลขครั้งก่อนและคำนวณหน่วยที่ใช้ให้ทันที เตือนถ้าเลขน้อยกว่าเดิม)
3. กด **บันทึกข้อมูล**
4. บนหน้าหลักจะเห็น **ยอดใช้วันนี้รวมทั้งโรงเรียน** ทั้งไฟฟ้า (kWh) และน้ำ (ลบ.ม.)

## ย้อนไปดู / แก้ข้อมูลวันเก่า

**บนหน้าหลัก** มีปุ่มลูกศร ← → ข้างวันที่ กดถอยหลังไปดูวันไหนก็ได้
จะเห็นว่าวันนั้นบันทึกจุดไหนไปแล้วบ้าง ตัวเลขเท่าไร แตะที่จุดเพื่อ **แก้ไขของวันนั้น**
ได้เลย (มีแถบสีฟ้าเตือนว่ากำลังแก้ย้อนหลัง) กด **"กลับมาวันนี้"** เพื่อกลับ

**อีกทางหนึ่ง** ในแท็บ **ประวัติ** แตะที่แถวไหนก็ได้ จะกระโดดไปแก้ของวันนั้นทันที
หรือในแท็บ **ตาราง** แตะที่วันที่ในคอลัมน์ซ้ายสุด

**ลบรายการที่ลงผิดวัน** — เข้าไปที่รายการนั้น เลื่อนลงล่างสุด
กด **"ลบรายการของวันนี้ทิ้ง"**

> แก้แล้วยอดใช้ของวันถัดไปจะคำนวณใหม่ให้เองอัตโนมัติ

## ดูตารางรายเดือน

แท็บ **ตาราง** คือสมุดจดแบบเดิม แต่คำนวณให้แล้ว — วันที่เรียงลงมา แต่ละจุดเรียงข้าง
เลื่อนซ้าย-ขวาเพื่อดูจุดอื่น แถวล่างสุดคือยอดรวมทั้งเดือนของแต่ละจุด

สลับดูได้ 2 แบบ:
- **หน่วยที่ใช้** — จำนวนหน่วยที่ใช้ในวันนั้น (เลขวันนั้น ลบ เลขครั้งก่อน)
- **เลขมิเตอร์** — เลขดิบที่อ่านได้จากหน้าปัด

ไฟฟ้ากับน้ำแยกกันคนละตาราง

## สิ้นเดือน ส่งบัญชี

ไปที่แท็บ **รายงาน** → เลือกเดือน → กด **"เปิดเอกสารส่งบัญชี (พิมพ์ / PDF)"**

จะได้เอกสาร A4 หน้าแรกเป็นใบสรุป:
- ยอดรวมไฟฟ้าและน้ำทั้งเดือน จำนวนจุด และจำนวนวันที่บันทึก
- ตารางแยกตามจุดและมิเตอร์ (เลขต้นเดือน / ปลายเดือน / หน่วยที่ใช้ / วันที่บันทึก)
- **ข้อสังเกตประจำเดือน** — จุดที่บันทึกไม่ครบทุกวัน และมิเตอร์ที่เลขต่ำกว่าครั้งก่อน
  (มักแปลว่าเปลี่ยนมิเตอร์ใหม่ หรือจดผิด) ให้ตรวจก่อนส่งบัญชี
- ช่องเซ็นชื่อ ผู้บันทึก / หัวหน้าช่าง / ฝ่ายบัญชี

จากนั้น **1 จุด = 1 แผ่น** เรียงต่อกัน แต่ละแผ่นขึ้นหน้าใหม่ หน้าตาเหมือนสมุด
ที่ทีมกรอกมือ: วันที่ 1–31 ไล่ลงมา เวลาที่เดินอ่าน มิเตอร์ละ 2 ช่อง
(เลขมิเตอร์ + จำนวนที่ใช้) ชื่อผู้บันทึก แถวรวม/เฉลี่ยต่อวัน หมายเหตุของวันนั้น
และช่องเซ็น CHECK BY / SITE SUPERVISOR / DATE — วันที่ไม่มีใครเดินจะเว้นเป็น
บรรทัดจางๆ ให้เห็นชัดว่าขาดวันไหน

อยากให้มีหมายเลขมิเตอร์ (Meter No.) บนแผ่นด้วย ให้ไปที่ **ตั้งค่า → จุดมิเตอร์**
→ กด "มิเตอร์" ที่จุดนั้น แล้วพิมพ์เลขลงช่อง "เลขมิเตอร์" ของแต่ละตัว

กด **พิมพ์ / PDF** → เลือกเครื่องพิมพ์เพื่อปริ้น หรือเลือก **"บันทึกเป็น PDF"**
เพื่อส่งไฟล์ให้บัญชีทางอีเมล/LINE

ถ้าบัญชีอยากได้เป็นไฟล์ Excel มีปุ่มดาวน์โหลด CSV ให้ 4 แบบด้านล่าง
(สรุปรายเดือน / ยอดใช้รายวัน / ตารางรายเดือน / รายละเอียดทุกมิเตอร์)

## เรื่องความปลอดภัย (อ่านสักครั้ง)

กฎ Firestore ที่ให้วางในขั้นที่ 2 เปิดให้ **ใครก็ตามที่มีลิงก์** อ่านและเขียนข้อมูลได้
เพราะแอปนี้ไม่ได้ใช้ระบบล็อกอินเต็มรูปแบบ (รหัส PIN ใช้แค่ระบุว่าใครเป็นคนบันทึก
ไม่ใช่ด่านกันคนนอก)

สิ่งที่ควรทำ:
- **ส่งลิงก์เฉพาะในกลุ่มช่าง 8 คน** อย่าโพสต์สาธารณะ
- ข้อมูลในนี้เป็นแค่เลขมิเตอร์กับรูปถ่ายมิเตอร์ ไม่มีข้อมูลส่วนตัวหรือข้อมูลการเงิน
  ความเสี่ยงจึงต่ำ

ถ้าภายหลังต้องการความปลอดภัยมากขึ้น (เช่น ให้ล็อกอินด้วยอีเมลรายคนจริงๆ)
บอกได้ครับ จะปรับให้ใช้ Firebase Authentication แล้วรัดกฎให้แน่นขึ้น

## ข้อจำกัดของโควตาฟรี

Firebase ฟรีให้ อ่าน 50,000 ครั้ง/วัน เขียน 20,000 ครั้ง/วัน และพื้นที่ 1 GB
ทีม 8 คน บันทึกวันละ 10 จุด ใช้ไม่ถึง 1% ของโควตา

รูปถ่ายถูกย่อขนาดอัตโนมัติในเครื่องก่อนอัปโหลด (จาก 3 MB เหลือประมาณ 60 KB)
ถ้าใช้ไปนานๆ แล้วอยากคืนพื้นที่ ไปที่ **ตั้งค่า › ข้อมูล › ลบรูปที่เก่ากว่า 120 วัน**
ตัวเลขมิเตอร์และรายงานย้อนหลัง **ไม่ถูกลบ**
