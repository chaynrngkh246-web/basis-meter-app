# พูดอังกฤษได้ — เรียนอังกฤษจากศูนย์ จนถึงระดับใช้ทำงาน

แอปฝึกภาษาอังกฤษภาษาไทยล้วน เริ่มจาก "ไม่เป็นเลย" ไปจนถึงประชุมและสัมภาษณ์งานได้

## 🔇 ไม่มีเสียง แก้ยังไง

แอปจะตรวจให้เองว่าเสียงออกหรือไม่ ถ้าไม่ออกจะขึ้นแถบเล็กๆ ด้านล่างพร้อมวิธีแก้ กดปุ่ม **🔊 ทดสอบเสียง**
บนหน้าแรกได้ตลอดเวลา ถ้ายังเงียบให้ไล่ตามนี้:

1. **กดปุ่มเพิ่มเสียงข้างเครื่อง ขณะที่อยู่ในแอปนี้** — ต้องเป็นระดับเสียง "สื่อ/มีเดีย" ไม่ใช่เสียงกริ่ง
2. **iPhone:** สวิตช์ปิดเสียงข้างซ้ายบนต้อง **ไม่** เห็นแถบสีส้ม (โหมดเงียบทำให้ไม่มีเสียงอ่าน)
3. **ถอดหูฟัง / ตัดลำโพงบลูทูธ** แล้วลองใหม่
4. **เปิดจากเบราว์เซอร์จริง** (Chrome / Safari) ไม่ใช่จากในแอปแชท
5. **Android:** ต้องมีแอป **Google Text-to-speech** ในเครื่อง (โหลดฟรีจาก Play Store)

> เสียงบนมือถือจะเริ่มทำงานหลังจากคุณ **แตะหน้าจอครั้งแรก** เท่านั้น (เป็นกฎของเบราว์เซอร์ทุกยี่ห้อ)
> แอปจัดการให้แล้ว แค่แตะปุ่มอะไรก็ได้หนึ่งครั้ง

> ⚠️ ส่วนที่ "ฟังเสียงพูด" ใช้ Web Speech API ทำงานได้ดีที่สุดบน **Chrome** (Android / Windows / Mac)
> และ **Safari รุ่นใหม่** บน iPhone ถ้าเบราว์เซอร์ไม่รองรับ แอปจะเปลี่ยนเป็น "พิมพ์คำตอบแทน" ให้อัตโนมัติ
> ครั้งแรกที่กดไมค์ เบราว์เซอร์จะถามขออนุญาตใช้ไมโครโฟน — ต้องกด "อนุญาต"

## วิธีสอนที่ใช้ในแอปนี้ (และทำไมถึงเลือกแบบนี้)

งานวิจัยด้านการเรียนภาษาที่สองชี้ตรงกันว่า ผู้เริ่มต้นจากศูนย์ต้องการ 4 อย่างนี้
แอปจึงถูกออกแบบให้วนครบทั้ง 4 ขั้นในทุกบท:

| ขั้น | สิ่งที่ทำ | ทำไม |
|---|---|---|
| 1. **รู้จักคำ** | เห็นประโยค + คำอ่านภาษาไทย + คำแปล + ฟังเสียงเจ้าของภาษา | ผู้เริ่มต้นต้องได้ *input ที่เข้าใจได้* (comprehensible input) ก่อน ไม่ใช่ท่องกฎไวยากรณ์ |
| 2. **พูดตาม (shadowing)** | ฟังแล้วพูดตามทันที แอปให้คะแนนการออกเสียง | การพูดตามฝึกทั้งหู ปาก และกล้ามเนื้อพร้อมกัน เป็นเทคนิคที่มีงานวิจัยรองรับเรื่องการออกเสียงและการจำ |
| 3. **แปลไทย → พูดอังกฤษ** | เห็นภาษาไทย แล้วต้องพูดอังกฤษออกมาเอง | เปลี่ยนจาก "จำได้" เป็น "ใช้เป็น" (output practice) |
| 4. **บทสนทนา** | สวมบทเป็นตัวเองในสถานการณ์จริง พูดโต้ตอบกับคู่สนทนา | ภาษาถูกใช้เป็นบทสนทนา ไม่ใช่คำเดี่ยวๆ |

เสริมด้วยหลักอีก 3 ข้อ:

- **จำเป็นก้อน ไม่ใช่คำเดี่ยว (lexical chunks)** — ทุกอย่างในแอปเป็นประโยคที่เอาไปพูดได้ทันที
  เช่น *"Can I have the menu?"* ไม่ใช่สอนคำว่า *menu* ลอยๆ ผู้เริ่มต้นจะได้ไม่ต้องแต่งประโยคเอง
- **ทบทวนแบบเว้นระยะ (spaced repetition)** — ใช้ระบบ Leitner คำที่ตอบถูกจะถูกเลื่อนไปทบทวนที่
  1 → 2 → 4 → 8 → 16 → 32 วัน คำที่ตอบผิดกลับมาทันที เพื่อทบทวน "ตอนที่กำลังจะลืมพอดี"
- **ไม่กดดัน** — มีปุ่ม 🐢 ฟังช้าๆ, 💡 ดูเฉลย, ⌨️ พิมพ์แทน อยู่ทุกหน้า ผิดได้ไม่มีการหักคะแนน

## เนื้อหาในแอป

**4 ระดับ · 25 บท · 300 ประโยค** พร้อมบทสนทนาบทละ 1 ชุด ทุกประโยคมีคำอ่านภาษาไทย
คำแปล และประโยคตัวอย่างครบ เลือกระดับได้เองจากแถบด้านบนหน้าแรก

| ระดับ | ชื่อ | เทียบ CEFR | บทเรียน |
|---|---|---|---|
| 🌱 1 | เริ่มจากศูนย์ | A0 | ทักทาย · ตัวเลข/เวลา · ครอบครัว · อาหาร · ซื้อของ · เดินทาง · งาน · สุขภาพ · คุยเล่น · โทรศัพท์ |
| 🌿 2 | พื้นฐานแน่น | A1–A2 | เล่าอดีต · พูดถึงอนาคต · ตั้งคำถาม · บอกตำแหน่งสิ่งของ · เปรียบเทียบ |
| 🌳 3 | ใช้งานได้จริง | B1 | แสดงความเห็น · นัดหมาย · อธิบายแก้ปัญหา · เล่าประสบการณ์ · ขอร้องปฏิเสธอย่างสุภาพ |
| 🏆 4 | ระดับมืออาชีพ | B2–C1 | ประชุมงาน · นำเสนองาน · เจรจาต่อรอง · สัมภาษณ์งาน · อีเมลและดูแลลูกค้า |

**🎯 แบบวัดระดับ** — 12 ข้อ ไม่ถึง 2 นาที บอกว่าควรเริ่มเรียนที่ระดับไหน

**💬 คุยโต้ตอบ** — 10 สถานการณ์แยกตามระดับ ตั้งแต่แนะนำตัวไปจนถึงประชุมกับทีมต่างชาติ
สัมภาษณ์งาน เจรจากับซัพพลายเออร์ และรับมือลูกค้าไม่พอใจ ติวเตอร์สวมบทเป็นคู่สนทนา
ผู้เรียนต้องทั้ง **ตอบ** และ **ถามกลับ** บทสนทนาเดินหน้าตามสิ่งที่ผู้เรียนพูดจริง

การตรวจคำตอบเข้มงวด — ตรวจว่ามีโครงประโยคที่ถูกต้องไหม (เช่น ต้องมี *my name is*)
มีเนื้อหาคำตอบครบไหม (ชื่อ อาชีพ ตัวเลข) และเหมือนประโยคตัวอย่างแค่ไหน
**ตอบมั่วจะไม่ผ่าน** ตอบผิดจะให้แก้ตัวที่ตาเดิม ครบสองครั้งจึงเฉลย

**❓ ถามติวเตอร์เอง** — ไม่ต้องรอให้แอปสั่งว่าต้องถามอะไร กดปุ่ม "ถามติวเตอร์" ได้ทุกเมื่อ
(ทั้งในระหว่างบทสนทนา และในโหมดถามอิสระ) แล้วถามอะไรก็ได้เป็นภาษาอังกฤษ
ติวเตอร์ชื่อ Anna (ครูจากแคนาดาที่อยู่กรุงเทพ) จะตอบเป็นภาษาอังกฤษพร้อมคำแปลไทย

- **คลังคำตอบ 33 เรื่อง** — เรื่องตัวติวเตอร์ (ชื่อ อายุ บ้านเกิด งาน ครอบครัว ความชอบ)
  ขอความช่วยเหลือ (พูดช้าลง พูดอีกครั้ง ผมควรพูดว่าอะไร) และคุยเล่น
- **คำถามเฉพาะสถานการณ์** — ทั้ง 10 ฉากมีคำตอบของตัวเอง ถาม *"What do you recommend?"*
  ในร้านอาหารได้แกงเขียวหวาน ถามในร้านเสื้อผ้าได้เรื่องห้องลอง
- **ถามคำแปลได้** — *"What does delicious mean?"* แอปค้นจาก 300 ประโยคในหลักสูตรมาตอบว่า "อร่อย"
- **ถามผิดรูปประโยคก็บอกให้** — พูดว่า *"you like coffee?"* ติวเตอร์ตอบให้ แล้วบอกว่า
  ประโยคที่ถูกคือ *"Do you like coffee?"* พร้อมปุ่มฟัง
- **พูดประโยคบอกเล่าแทนคำถาม** ก็ทักให้ว่าอันนี้ยังไม่ใช่คำถาม

**🎓 ยกระดับ: พูดให้เหมือนเจ้าของภาษา** — 32 ประโยคที่เทียบให้เห็น 3 ระดับของ
สถานการณ์เดียวกัน พร้อมอธิบายว่าต่างกันตรงไหน:

| ระดับ | ตัวอย่าง |
|---|---|
| พื้นฐาน | *Give me menu.* |
| ดีขึ้น | *Can I have the menu, please?* |
| เจ้าของภาษา | *Could we see the menu, please?* |

## 👩‍🏫 ครูในตัวแอป

เปิดแอปมาไม่ต้องเลือกอะไรเลย ครูจัดให้พร้อมแล้ว — นี่คือส่วนที่ตั้งใจออกแบบมากที่สุด
เพราะคนที่เริ่มจากศูนย์ **ไม่รู้ว่าควรเริ่มตรงไหน** ถ้าให้เลือกเองมักจะไม่ได้เริ่มสักที

**แผนวันนี้** — ครูเลือกให้ 3 อย่าง รวมประมาณ 10–12 นาที กดปุ่มเดียวไล่ไปทีละอย่าง
ติ๊กถูกทีละข้อ ขึ้นวันใหม่แผนรีเซ็ตเอง:

1. **ทบทวนคำเก่า** — เฉพาะคำที่ถึงกำหนดตามระบบเว้นระยะ (ข้ามถ้ายังไม่มี)
2. **เรียนบทต่อไป** — ต่อจากที่ค้างไว้เป๊ะ ไม่ต้องหาเอง
3. **แก้จุดอ่อน หรือ คุยจริง** — ถ้ามีจุดที่พลาดซ้ำจะพามาแก้ ถ้าไม่มีก็พาไปคุยโต้ตอบ

**ครูทักทายและจำคุณได้** — ถามชื่อครั้งเดียว แล้วเรียกชื่อทุกครั้ง ทักตามช่วงเวลาของวัน
และเล่าให้ฟังว่าเมื่อวานฝึกไปกี่ข้อ หรือต่อเนื่องมากี่วันแล้ว

**บทเรียนพักทุก 12 ข้อ** — เดิมบทละ 46 ข้อรวดเดียวซึ่งยาวเกินไปจนคนเลิกกลางคัน
ตอนนี้ครบ 12 ข้อจะมีจุดพักให้เลือก "ไปต่อ" หรือ "พอแค่นี้ก่อน" และ**จำตำแหน่งไว้ให้**
พรุ่งนี้มาต่อจากตรงนั้นได้เลย

## 🩺 คลินิกแก้จุดอ่อน

ทุกครั้งที่พูดผิด แอปไม่ได้แค่บอกว่าผิด แต่**จำประเภทความผิดไว้** พอพลาดเรื่องเดิมครบ
3 ครั้ง ครูจะทักขึ้นมาว่า *"ครูสังเกตเห็นว่า… คุณพลาดเรื่องลืม is/am/are ไปแล้ว 7 ครั้ง"*
แล้วเปิดคลินิกให้ 3 นาที

คลินิกสอนก่อน แล้วค่อยให้ฝึก:

| ส่วน | เนื้อหา |
|---|---|
| **ทำไมถึงผิด** | อธิบายเทียบกับภาษาไทย — *"ภาษาไทยพูดว่า 'ผมครู' ได้เลย แต่ภาษาอังกฤษต้องมีคำเชื่อมเสมอ"* |
| **จำแค่นี้พอ** | กฎสั้นที่สุดที่ใช้ได้จริง — *"I → am · He/She/It → is · You/We/They → are"* |
| **แบบที่คนไทยมักพูดผิด** | ให้เห็นว่าอะไรคือสิ่งที่ต้องเลิก |
| **ตัวอย่างที่ถูก** | แตะฟังได้ทีละประโยค |
| **ฝึกพูด 5 ประโยค** | ดึงจาก 300 ประโยคในหลักสูตร เลือกเฉพาะประโยคที่มีจุดนั้น |

ครอบคลุม 9 จุดอ่อนที่คนไทยพลาดบ่อยที่สุด: ลืม is/am/are · ลืม a/an/the · ลืมเสียง s ท้ายคำ ·
ลืม -ed ของอดีต · ลืมกริยาช่วย do/did/will · และเสียง **th · v · r · l ท้ายคำ**

ฝึกผ่านแล้วตัวนับจุดอ่อนจะลดลง ถ้ายังพลาดอีกครูก็ชวนมาซ้อมใหม่

## 🔍 ตัวโค้ช: ผิดตรงไหน ต้องแก้ยังไง

ทุกครั้งที่พูดผิด แอปจะไม่บอกแค่ "ผิด" แต่จะ:

1. **จับคู่คำที่พูดกับประโยคที่ถูก** แล้วระบายสีทีละคำ — 🟢 ถูก · 🔴 ผิดคำ · ⬛ ไม่ได้พูด
2. **วิเคราะห์เป็นภาษาไทยว่าเป็นข้อผิดพลาดแบบไหน** เน้นจุดที่คนไทยพลาดบ่อยที่สุด:
   - ลืม verb to be (is / am / are) — เพราะภาษาไทยไม่มีคำว่า "เป็น/อยู่/คือ" ในประโยคแบบนี้
   - ลืม a / an / the หน้าคำนาม
   - ลืมเสียง **s** ท้ายคำ และ **-ed** ของอดีต
   - ตัดกริยาช่วย (do / did / will / can) ทิ้ง
   - เสียงที่คนไทยออกยาก: **th** · **v** · **r** · **l** ท้ายคำ
3. **ปุ่มฟังทีละคำ** — อ่านประโยคช้าๆ ทีละคำพร้อมไฮไลต์คำที่กำลังอ่าน

ตัวให้คะแนนตั้งใจให้ผ่อนปรน (พูดใกล้เคียงก็ผ่าน) แต่ **ตัวโค้ชตั้งใจให้เข้มงวด**
เพราะการลืม s หรือ -ed คือสิ่งที่ผู้เรียนต้องรู้ ไม่ใช่สิ่งที่ควรปล่อยผ่าน

## ตารางเรียนที่แนะนำ

| ช่วง | ทำอะไร | ใช้เวลา |
|---|---|---|
| ครั้งแรกสุด | 🎯 **วัดระดับ** เพื่อรู้ว่าควรเริ่มตรงไหน | 2 นาที |
| **ทุกวัน** | เปิดแอป กด **▶ เริ่มเลย** แล้วทำตาม **แผนวันนี้** จนครบ | **10–12 นาที** |
| สัปดาห์ละครั้ง | แท็บ 🎓 **ยกระดับ** ดูว่าเจ้าของภาษาพูดยังไง | 10 นาที |

แค่ทำตามแผนวันนี้ทุกวันก็พอ ไม่ต้องคิดเองว่าจะเรียนอะไร — ครูจัดให้แล้ว

ทำแบบนี้ทุกวันประมาณ 6–8 สัปดาห์ จะจบระดับ 1 ทั้งหมด และพูดประโยคพื้นฐานได้เองโดยไม่ต้องคิดนาน
จากนั้นไต่ระดับ 2 → 3 → 4 ต่อไปได้เรื่อยๆ จนถึงระดับที่ใช้ประชุมและสัมภาษณ์งานเป็นภาษาอังกฤษได้
**สำคัญที่สุดคือทำทุกวัน** — วันละ 15 นาทีได้ผลกว่าอาทิตย์ละ 3 ชั่วโมงรวดเดียว

## สำหรับนักพัฒนา

```bash
npm run build     # สร้าง index.html, docs/index.html, artifact/app.html, sw.js, manifest
npm run icons     # สร้างไอคอนแอปใหม่จาก scripts/icon-source.html (ทำเมื่อจะเปลี่ยนไอคอน)
npm run share-image  # สร้างรูปพรีวิวตอนแชร์ลิงก์ใหม่จาก scripts/share-source.html
npm run qr        # สร้าง QR code ของลิงก์แอปใหม่ (ทำเมื่อเปลี่ยนลิงก์)
npm test          # ทดสอบแอปจริงในเบราว์เซอร์ (ต้องมี playwright)
npm run serve     # เปิดเซิร์ฟเวอร์ที่ http://localhost:8080
```

โครงสร้าง:

```
src/app.fragment.html   ← ไฟล์ต้นฉบับไฟล์เดียว (แก้ที่นี่ที่เดียว)
scripts/build.mjs       ← สร้างไฟล์ผลลัพธ์
tests/e2e.mjs           ← ทดสอบการใช้งานจริงในเบราว์เซอร์
index.html              ← ผลลัพธ์ (สร้างอัตโนมัติ อย่าแก้ตรงนี้)
docs/                   ← ผลลัพธ์สำหรับ GitHub Pages
artifact/app.html       ← ผลลัพธ์สำหรับเผยแพร่เป็น Artifact
docs/sw.js              ← service worker (ทำให้ติดตั้งเป็นแอปได้ และใช้ออฟไลน์ได้)
docs/icon-*.png         ← ไอคอนแอป สร้างจาก scripts/make-icons.mjs
docs/share.png          ← รูปพรีวิวตอนแชร์ลิงก์ สร้างจาก scripts/make-share-image.mjs
src/qr.svg              ← QR code ของลิงก์แอป ฝังเข้าหน้าเว็บตอน build
tests/qr.mjs            ← ตรวจว่า QR ตรงกับไลบรารีมาตรฐานทุกช่อง
```

**โครงสร้างข้อมูลใน `src/app.fragment.html`**

| ตัวแปร | คืออะไร |
|---|---|
| `LEVELS` | 4 ระดับ พร้อมชื่อไทยและเทียบ CEFR |
| `COURSE` | 25 บท แต่ละบทมี `level`, `words[12]`, `dialog` |
| `SCENES` | 10 สถานการณ์สนทนา แต่ละตามี `need` / `oneOf` / `extra` ไว้ตรวจคำตอบ |
| `UPGRADES` | 32 ประโยคเทียบ 3 ระดับ พร้อม `note` อธิบาย |
| `ASKS` | 33 คำตอบของติวเตอร์ เวลาผู้เรียนถามเอง (`keys` = คำที่ต้องมีครบ) |
| `SCENES[].qa` | คำตอบเฉพาะสถานการณ์ของแต่ละฉาก |
| `WEAK_INFO` | 9 จุดอ่อนที่คนไทยพลาดบ่อย พร้อมคำอธิบายและตัวอย่างสำหรับคลินิก |
| `buildPlan()` | ตัวจัดแผนประจำวัน 3 ขั้น |

**เพิ่มบทเรียนใหม่** — เพิ่มใน `COURSE` ตามรูปแบบเดิม (`words` ต้องมี `en`, `th`,
`ph` (คำอ่านไทย), `ex`, `exth` และ `dialog.lines` ใช้ `who: "You"` สำหรับบรรทัดที่ผู้เรียนพูด)
แล้วรัน `npm run build` — ชุดทดสอบจะเช็คให้เองว่าข้อมูลครบทุกช่อง

**เพิ่มสถานการณ์สนทนา** — เพิ่มใน `SCENES` แต่ละตาต้องมี `say` (บอกเป็นไทยว่าให้พูดอะไร),
`model` + `modelTh` (ประโยคเฉลย) และวิธีตรวจอย่างน้อยหนึ่งอย่าง: `need` (ชุดคำที่ต้องมีครบ),
`oneOf` (ต้องมีอย่างน้อยหนึ่งคำ), `extra` (ต้องมีคำเนื้อหาเพิ่มกี่คำ)
ตั้ง `askBack:true` + `botReply` สำหรับตาที่ผู้เรียนต้องเป็นฝ่ายถาม

ข้อมูลความคืบหน้าทั้งหมดเก็บใน `localStorage` ของเครื่องผู้ใช้เท่านั้น ไม่มีการส่งข้อมูลออกไปที่ใด
