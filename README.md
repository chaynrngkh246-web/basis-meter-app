# พูดอังกฤษได้ — แอปสอนภาษาอังกฤษสำหรับคนที่เริ่มจากศูนย์

แอปฝึกภาษาอังกฤษภาษาไทยล้วน สำหรับคนที่ "ไม่เป็นเลย" ให้พูดออกมาได้จริง
เน้น **พูดออกเสียงจริงผ่านไมโครโฟน** แล้วแอปบอกทันทีว่าออกเสียงชัดกี่เปอร์เซ็นต์
ไม่ต้องสมัครสมาชิก ไม่ต้องต่อเซิร์ฟเวอร์ ไม่ต้องใช้ API key — เปิดแล้วเรียนได้เลย

## 📲 ติดตั้งลงมือถือ (ทำครั้งเดียว)

**ขั้นที่ 1 — เอาลิงก์ของแอปมาก่อน**

repo นี้มี GitHub Actions ที่เผยแพร่แอปให้อัตโนมัติทุกครั้งที่ push
ลิงก์ของคุณคือ `https://chaynrngkh246-web.github.io/basis-meter-app/`

ถ้าเปิดแล้วขึ้น 404 แปลว่ายังไม่ได้เปิด GitHub Pages — เปิดครั้งเดียวจบ:
ไปที่ **Settings → Pages → Build and deployment → Source** เลือก **GitHub Actions**
แล้วไปที่แท็บ **Actions** กด run workflow ชื่อ *Deploy to GitHub Pages* อีกครั้ง

**ขั้นที่ 2 — ติดตั้งลงหน้าจอโฮม**

| เครื่อง | วิธีทำ |
|---|---|
| **iPhone / iPad** | เปิดลิงก์ด้วย **Safari** → กดปุ่ม **แชร์** ⬆️ ที่แถบล่าง → เลื่อนหา **"เพิ่มไปยังหน้าจอโฮม"** → กด **เพิ่ม** |
| **Android** | เปิดลิงก์ด้วย **Chrome** → กดเมนู **⋮** มุมขวาบน → **"ติดตั้งแอป"** หรือ **"เพิ่มลงในหน้าจอหลัก"** |

ในแอปมีการ์ด **📲 ติดตั้งลงมือถือ** อยู่บนหน้าแรกและในแท็บตั้งค่า
ซึ่งจะตรวจเครื่องให้เองแล้วบอกขั้นตอนที่ตรงกับเครื่องคุณ (บน Android จะมีปุ่มติดตั้งให้กดปุ่มเดียว)

> ⚠️ **ห้ามเปิดจากในแอป LINE / Facebook / Messenger** — พวกนี้ใช้เบราว์เซอร์ในตัวที่ติดตั้งแอปไม่ได้และมักไม่มีเสียง
> ให้กดเมนู ⋯ แล้วเลือก **"เปิดในเบราว์เซอร์"** ก่อนเสมอ

**บนคอมพิวเตอร์** — ดับเบิลคลิกไฟล์ `index.html` ได้เลย (แนะนำ Google Chrome)

## 🔇 ไม่มีเสียง แก้ยังไง

แอปจะตรวจให้เองว่าเสียงออกหรือไม่ ถ้าไม่ออกจะขึ้นแถบเล็กๆ ด้านล่างพร้อมวิธีแก้ กดปุ่ม **🔊 ทดสอบเสียง**
บนหน้าแรกได้ตลอดเวลา ถ้ายังเงียบให้ไล่ตามนี้:

1. **กดปุ่มเพิ่มเสียงข้างเครื่อง ขณะที่อยู่ในแอปนี้** — ต้องเป็นระดับเสียง "สื่อ/มีเดีย" ไม่ใช่เสียงกริ่ง
2. **iPhone:** สวิตช์ปิดเสียงข้างซ้ายบนต้อง **ไม่** เห็นแถบสีส้ม (โหมดเงียบทำให้ไม่มีเสียงอ่าน)
3. **ถอดหูฟัง / ตัดลำโพงบลูทูธ** แล้วลองใหม่
4. **เปิดจากเบราว์เซอร์จริง** (Chrome / Safari) ไม่ใช่จากในแอปแชท
5. **Android:** ต้องมีแอป **Google Text-to-speech** ในเครื่อง (โหลดฟรีจาก Play Store)

> เสียงบนมือถือจะเริ่มทำงานหลังจากคุณ **แตะหน้าจอครั้งแรก** เท่านั้น (เป็นกฎของเบราว์เซอร์ทุกยี่ห้อ)
> แอปจัดการให้แล้ว แค่แตะปุ่มอะไรก็ได้หนึ่งครั้ง

> ⚠️ ส่วนที่ "ฟังเสียงพูด" ใช้ Web Speech API ทำงานได้ดีที่สุดบน **Chrome** (Android / Windows / Mac)
> และ **Safari รุ่นใหม่** บน iPhone ถ้าเบราว์เซอร์ไม่รองรับ แอปจะเปลี่ยนเป็น "พิมพ์คำตอบแทน" ให้อัตโนมัติ
> ครั้งแรกที่กดไมค์ เบราว์เซอร์จะถามขออนุญาตใช้ไมโครโฟน — ต้องกด "อนุญาต"

## วิธีสอนที่ใช้ในแอปนี้ (และทำไมถึงเลือกแบบนี้)

งานวิจัยด้านการเรียนภาษาที่สองชี้ตรงกันว่า ผู้เริ่มต้นจากศูนย์ต้องการ 4 อย่างนี้
แอปจึงถูกออกแบบให้วนครบทั้ง 4 ขั้นในทุกบท:

| ขั้น | สิ่งที่ทำ | ทำไม |
|---|---|---|
| 1. **รู้จักคำ** | เห็นประโยค + คำอ่านภาษาไทย + คำแปล + ฟังเสียงเจ้าของภาษา | ผู้เริ่มต้นต้องได้ *input ที่เข้าใจได้* (comprehensible input) ก่อน ไม่ใช่ท่องกฎไวยากรณ์ |
| 2. **พูดตาม (shadowing)** | ฟังแล้วพูดตามทันที แอปให้คะแนนการออกเสียง | การพูดตามฝึกทั้งหู ปาก และกล้ามเนื้อพร้อมกัน เป็นเทคนิคที่มีงานวิจัยรองรับเรื่องการออกเสียงและการจำ |
| 3. **แปลไทย → พูดอังกฤษ** | เห็นภาษาไทย แล้วต้องพูดอังกฤษออกมาเอง | เปลี่ยนจาก "จำได้" เป็น "ใช้เป็น" (output practice) |
| 4. **บทสนทนา** | สวมบทเป็นตัวเองในสถานการณ์จริง พูดโต้ตอบกับคู่สนทนา | ภาษาถูกใช้เป็นบทสนทนา ไม่ใช่คำเดี่ยวๆ |

เสริมด้วยหลักอีก 3 ข้อ:

- **จำเป็นก้อน ไม่ใช่คำเดี่ยว (lexical chunks)** — ทุกอย่างในแอปเป็นประโยคที่เอาไปพูดได้ทันที
  เช่น *"Can I have the menu?"* ไม่ใช่สอนคำว่า *menu* ลอยๆ ผู้เริ่มต้นจะได้ไม่ต้องแต่งประโยคเอง
- **ทบทวนแบบเว้นระยะ (spaced repetition)** — ใช้ระบบ Leitner คำที่ตอบถูกจะถูกเลื่อนไปทบทวนที่
  1 → 2 → 4 → 8 → 16 → 32 วัน คำที่ตอบผิดกลับมาทันที เพื่อทบทวน "ตอนที่กำลังจะลืมพอดี"
- **ไม่กดดัน** — มีปุ่ม 🐢 ฟังช้าๆ, 💡 ดูเฉลย, ⌨️ พิมพ์แทน อยู่ทุกหน้า ผิดได้ไม่มีการหักคะแนน

## เนื้อหาในแอป

10 บท × 12 ประโยค = **120 ประโยคที่ใช้บ่อยที่สุดในชีวิตจริง** พร้อมบทสนทนาบทละ 1 ชุด

1. 👋 ทักทาย & แนะนำตัว
2. 🔢 ตัวเลข & เวลา
3. 👨‍👩‍👧 ครอบครัว & ผู้คน
4. 🍜 อาหาร & สั่งอาหาร
5. 🛍️ ซื้อของ & ราคา
6. 🚕 เดินทาง & ถามทาง
7. 💼 งาน & กิจวัตรประจำวัน
8. 🩺 ความรู้สึก & สุขภาพ
9. 🗣️ คุยเล่นกับฝรั่ง (small talk)
10. 📞 ที่ทำงาน & โทรศัพท์

**โหมดคุยกับติวเตอร์** — ติวเตอร์ถามคำถามเป็นภาษาอังกฤษทีละข้อ (24 คำถาม)
ผู้เรียนตอบด้วยเสียงจริง แอปตรวจแล้วตอบกลับ พร้อมปุ่มขอคำใบ้ทุกข้อ

## ตารางเรียนที่แนะนำ

| ช่วง | ทำอะไร | ใช้เวลา |
|---|---|---|
| ทุกเช้า | แท็บ 🔁 **ทบทวน** | 5 นาที |
| ทุกเย็น | แท็บ 🏠 **บทเรียน** ทีละบท | 10–15 นาที |
| ก่อนนอน | แท็บ 💬 **คุยกับติวเตอร์** 5 คำถาม | 5 นาที |

ทำแบบนี้ทุกวันประมาณ 4–6 สัปดาห์ จะจบครบ 10 บท และพูดประโยคพื้นฐานได้เองโดยไม่ต้องคิดนาน
**สำคัญที่สุดคือทำทุกวัน** — วันละ 15 นาทีได้ผลกว่าอาทิตย์ละ 3 ชั่วโมงรวดเดียว

## สำหรับนักพัฒนา

```bash
npm run build     # สร้าง index.html, docs/index.html, artifact/app.html จากไฟล์ต้นฉบับ
npm test          # ทดสอบแอปจริงในเบราว์เซอร์ (ต้องมี playwright)
npm run serve     # เปิดเซิร์ฟเวอร์ที่ http://localhost:8080
```

โครงสร้าง:

```
src/app.fragment.html   ← ไฟล์ต้นฉบับไฟล์เดียว (แก้ที่นี่ที่เดียว)
scripts/build.mjs       ← สร้างไฟล์ผลลัพธ์
tests/e2e.mjs           ← ทดสอบการใช้งานจริงในเบราว์เซอร์
index.html              ← ผลลัพธ์ (สร้างอัตโนมัติ อย่าแก้ตรงนี้)
docs/                   ← ผลลัพธ์สำหรับ GitHub Pages
artifact/app.html       ← ผลลัพธ์สำหรับเผยแพร่เป็น Artifact
```

**เพิ่มบทเรียนใหม่** — เปิด `src/app.fragment.html` หา `const COURSE = [` แล้วเพิ่มบทตามรูปแบบเดิม
(`words` ต้องมี `en`, `th`, `ph` (คำอ่านไทย), `ex`, `exth` และ `dialog.lines` ใช้ `who: "You"`
สำหรับบรรทัดที่ผู้เรียนต้องพูดเอง) แล้วรัน `npm run build`

ข้อมูลความคืบหน้าทั้งหมดเก็บใน `localStorage` ของเครื่องผู้ใช้เท่านั้น ไม่มีการส่งข้อมูลออกไปที่ใด
